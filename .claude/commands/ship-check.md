---
description: 上线前全维度检查
---

按顺序执行,任何一项不通过就停下来报告,不要自行跳过。

**代码与内容**
```
npm run ship
```
它会依次跑内容包校验、合规检查、国内环境体检、计分测试、类型检查和构建。

**真机验证**
模拟器测不出国产内核的差异。按 `docs/operations/china-devices.md` 第七节的清单，至少在微信 Android、微信 iOS、MIUI 浏览器、华为浏览器、UC 和抖音内置浏览器上各走一遍完整流程。重点看三件事：首屏有没有横向滚动、间距有没有挤成一团、点解锁有没有明确反馈。

**生产配置**
运行 `npm run check:prod-env -- --env-file <生产环境变量文件>`。确认:没有 mock 支付、没有占位密钥、没有 localhost 地址、备案域名已配置。

**支付链路**
确认预下单、回调验签、幂等、权益发放四段都有真实实现,回调重放不会重复发放权益。确认付费用户换设备后可以凭微信身份找回报告。

**合规**
调用 `compliance-reviewer` 对首页、结果页、付费页、隐私政策、用户协议做最后一遍审查。确认隐私政策覆盖了实际收集的每一项。

**分发**
查阅 `docs/operations/wechat-distribution.md`,确认域名池、被拦截兜底页、分享话术都已就位,并且没有任何诱导分享环节。

**回滚**
确认内容包版本冻结策略生效,历史结果按当时版本渲染。写下本次上线的回滚触发条件。

全部通过后更新 CHANGELOG.md。
