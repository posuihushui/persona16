---
description: 对内容包做质量与合规双重审查
argument-hint: [slug,默认全部]
---

审查目标:$ARGUMENTS

**第 1 轮 质量**
调用 `content-writer` 自审:
- 随机抽五对类型,互换核心描述,判断是否仍然读得通。读得通说明写虚了,列出具体句子。
- 找出所有巴纳姆式表达,就是换任何类型都成立的句子。
- 检查缺点部分是否落在可改善的行为上,而不是人身评价。

**第 2 轮 合规**
调用 `compliance-reviewer` 走完整审查清单,按商标版权、广告法、心理表达边界、个人信息、平台规则五组逐条给结论。

**第 3 轮 机器检查**
运行 `npm run check:content && npm run check:compliance`。

最后按严重程度汇总:阻断上线、上线前修、建议优化,每条给出文件和行号。
