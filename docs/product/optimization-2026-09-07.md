## 验收方式

自动测试覆盖计分稳定性、所有 16 种结果、恢复损坏索引 / 非法答案 / 旧版本、复制权限拒绝与旧内核回退、当前和归档版本隔离、全部类型的免费内容边界。

`npm run test:smoke` 只接受本地服务、本地数据库与 `PAY_PROVIDER=mock`。先启动本地服务再执行。它创建合成作答与模拟订单，检查版本冲突、缺题和非法选项、免费 HTML / API、noindex、折扣重复领取、模拟回调重复处理、报告权限与跨会话查询码找回、公开类型页和 llms 出口、16 张卡片接口。测试数据留在本地，来源标记为 `local-optimization-smoke`，不应进入线上指标。

浏览器走查已完成 48 题并提交结果，刷新后恢复进度；320×568 的类型、标签、关键词和两个分享按钮都在首屏，页面无横向溢出。375×667 成功生成 900×1200 PNG，图片内容与类型卡一致。

补充走查：768px 类型页无横向溢出，接收者可直接点击进入答题；双击只前进一题，刷新恢复 1 / 48，重新开始的取消操作保留进度。点击优惠后显示 5.94 元。本地模拟支付原先将 127.0.0.1 切换成 localhost，导致购买身份丢失；改为受限的相对报告路径后，实际点击支付成功进入原域名上的报告，验收脚本同时检查这个返回地址。

新增非结构性文案集中在 `content/ui.json`。免费结论、维度位置和关键词保持完整；折叠清单只含公开目录，付费正文继续在服务端截断。个人结果和报告保持 noindex，公开类型页面继续可索引。
